## Algebra-first build

Build with `node bootstrap/temple-seed.cjs`. The single seed uses Node builtins and executes the existing surface-process algebra. The executable modules in `algebra/` own page construction, CSS projection, browser and worker behaviour, assurance and build composition. The manifest is `bootstrap/site.json`; event content and presentation remain semantic REL inputs. The MJS module tree is outside the bootstrap dependency closure.

Run `node --test bootstrap/bootstrap.test.cjs` to prove the build in a fresh directory containing no MJS modules, legacy scripts or node_modules. The suite checks all eight pages, shared navigation, local links, deterministic artifacts, algebra mutation, refusal cases and generated browser/worker behaviour. The exact input and artifact hashes are recorded in `generated/bootstrap-proof.json`.

Differential qualification against the existing evaluator is recorded in `generated/bootstrap-conformance.json`. See [the bootstrap execution boundary](bootstrap/README.md) for host ports, supported algebra and reproduction commands. Node remains the seed host; no claim of a native or WASM runtime is made. The external Cloudflare worker is not redeployed by the static build.

GitHub Pages runs the isolated proof and then builds `dist/` through the seed. The retired MJS projector, build scripts, HTML-REL implementation and obsolete site manifest have been removed; earlier versions remain in Git history. Generated HTML, CSS and runtime JavaScript remain output. The bootstrap manifest and proof receipts describe the current executable closure; the launch receipt records the historical deployment.
